正午的阳光透过窗户斜斜地照在书桌上，光线把桌面照得透亮，连平时不太注意的键盘缝隙里那些细小的微尘也看得一清二楚。正好趁着午休有一段完整安静的空闲，决定给用了好几个月的这把客制化机械键盘来一次彻底的“大扫除”。

从抽屉里翻出细钢丝拔键器、小气吹和一把羊毛软毛刷。把键盘线拔掉，将木质托盘推到面前，清洁工程正式开始。

---

### 拔键与分类的节奏感

用拔键器对准键帽边缘轻轻卡住，垂直向上稍稍发力，伴随着一声声清脆利落的“嗒、嗒”声，键帽一颗颗脱离开轴心。

为了等会儿安装时不用满桌子找位置，我特意按着字母区、功能区和小键盘的顺序把它们排在木托盘里。看着原本满满当当的键盘逐渐露出整齐排列的轴体，心情莫名变得格外放松。

拔完大键位的平衡杆时最需要耐心，慢慢解开龙豆，把每一个小配件都收拢在小盒子里。

```
[ Esc ] [ F1 - F12 ]
[ `~ ]  [ 1 - 0 ] [ Backspace ]
[ Tab ] [ Q - P ] [ \ | ]
```

---

### 细致拂去每一处缝隙的微尘

卸掉全部键帽后，定位板上的灰尘一览无余。

- **第一步：气吹除尘**  
  先拿捏紧橡皮气吹，对着轴与轴之间的十字凹槽和定位板边角连续按压，将深层积攒的浮尘统统吹散。
- **第二步：软毛刷轻扫**  
  再用细软的羊毛刷沿着轴体的缝隙仔细打圈轻扫，配合微湿的无尘布将定位板表面擦拭得干干净净。
- **第三步：键帽擦拭**  
  每一颗键帽都用干布仔细擦去指尖留下的微油，让哑光磨砂质感重新显现出来。

在正午明亮的日光下，看着黑色的定位板重新恢复深邃哑光的质感，原本细碎的烦躁感也跟着被彻底抚平了。

---

### 重新按回轴体的治愈瞬间

把键帽重新按回轴心是整个过程里最解压的环节。

对准十字轴心轻轻向下按压，能清晰感受到轴体内部弹簧的回弹与清脆的卡扣合拢声。“咔哒、咔哒”，从空格键一路装回回车键，原本光秃秃的定位板再次被排列得整整齐齐。

随手在文本编辑器里敲下几行文字测试按键，没有了杂灰的阻碍，每个按键的触底与回弹都变得格外干净利落，声音听起来像秋日清晨踩在干燥落叶上的脆响。

把书桌擦抹一新，换上一杯温热的玄米茶，看着眼前焕然一新的键盘，下午的精神也一下子被完全唤醒了 ✨
